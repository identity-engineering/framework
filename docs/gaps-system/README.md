# Gaps system

Public Critical Gaps for Identity Engineering are tracked as **GitHub issues** with the label `gap`.

| Doc | Purpose |
|-----|--------|
| [SKILL.md](./SKILL.md) | Operating rules for humans and agents |
| [LABELS.md](./LABELS.md) | Canonical label list |
| [MIGRATION.md](./MIGRATION.md) | One-time migration from static site content |

Issue template: [`.github/ISSUE_TEMPLATE/gap.yml`](../../.github/ISSUE_TEMPLATE/gap.yml)

Philosophy: every gap is solvable (or explicitly accepted), public, and part of the living framework.
